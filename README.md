# Raphix Lab

Central hub for my hardware, software, electronics, retro-gaming and fabrication projects.

## Projects

### Catmasys

Catalog and collection system for the Brazilian Master System library.

**Type:** Software / Web / Database

**Repository:** [Catmasys](https://github.com/raphix-br/Catmasys)

---

### UCRT — Universal CRT Controller

Modular controller project for CRT displays, initially targeting the CCE HPS-2073A / chassis 34BI.

**Type:** Electronics / Hardware / Firmware

**Repository:** [UCRT](https://github.com/raphix-br/UCRT)

---

### Raphix 8-bit

Future project for a custom 8-bit video game system.

**Type:** Hardware / Electronics / Firmware / Software

**Status:** Planned

---

### CRT Cabinet

Physical cabinet and furniture project for integrating CRT hardware, controls and electronics.

**Type:** Mechanical / Carpentry / Fabrication

**Status:** Planned

The Raphix Lab repository serves as the central documentation and navigation hub connecting the projects.
